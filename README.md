# Parallight Lab — Codex CLI plugin (BETA)

Pre-release Codex builds for invited testers. Points at the **beta** backend
(`beta.lab-agent.parallight.ai`), isolated from the public release.

## Install (Codex CLI)

```
codex plugin marketplace add parallight/lab-codex-beta
codex plugin add parallight-lab@parallight-cx-beta
```

Restart Codex, then use the `:lab` commands (`:lab-login`, `:lab`,
`:lab-start lab-01`) or natural language. Your email must be on the beta
allowlist. The stable release: <https://parallight.ai/install>
